# 🚀 Professional Portfolio - Jerome V. Morales

A high-end, responsive personal portfolio built with **Spring Boot** and **Thymeleaf**. This project showcases a modular architecture and modern UI/UX design.

## 🛠️ Tech Stack
*   **Backend:** Java, Spring Boot
*   **Frontend Engine:** Thymeleaf (Modular Fragments)
*   **Styling:** Modern CSS3 (Glassmorphism, CSS Grid, Flexbox)
*   **Interactions:** Vanilla JavaScript
*   **Forms:** Formspree API Integration
*   **Icons:** Inline SVG & Font Awesome

## ✨ Key Features
*   **Modular Architecture:** Uses Thymeleaf fragments for a clean, maintainable codebase.
*   **Dark Mode Aesthetic:** Sleek violet and dark-blue theme with glassmorphism effects.
*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
*   **Custom Animations:** Features a custom JVM-inspired loading animation.
*   **Anti-Lag Logic:** Optimized script loading to prevent browser collisions.

## 📂 Project Structure
* `/fragments`: Reusable UI components (Hero, About, Experience, etc.)
* `/static/css`: Custom design variables and responsive media queries.
* `/static/js`: Interactive elements and form handling.
